### 为什么数字电位器用软件 SPI

原理图上 CS/SCK/SI 接 PA4/PA5/PA6，而 SPI1 的默认映射是 SCK=PA5、MISO=PA6、MOSI=PA7。
SI 落在 PA6（MISO 脚）上，硬件 SPI 发不出数据，所以驱动用 GPIO 翻转时序
（`drv_mcp41010.c`）。如果改板挪到真正的 MOSI，把 `mcp_xfer()` 换成
`HAL_SPI_Transmit()` 即可。

### 为什么要软件控制 CS

HAL 的硬件 NSS 在每次 `HAL_SPI_Transmit` 结束后自动抬高片选，会把一帧 16 个时钟切成两帧。
MCP41010 以 CS 上升沿作为帧结束，切碎了整帧作废 —— 现象是"代码不报错，但音量不动"。

## 供电

两级：USB 5V 直接给 NE5532 与 TDA2822，AMS1117-3.3 降到 3.3V 给 STM32、CD4066、
MCP41010 与 OLED。

注意 NE5532 在单 5V 下输入共模范围有限，虚地取 2.5V 是折中：
信号摆幅被压在约 0.4~4.6V（±2.1V 相对虚地），这也是满音量削顶的直接原因。
